# Modern C# Surface Matrix

This matrix tracks C# 12 through C# 14 language surfaces against the SharpProof
proof areas they can affect. It is a planning and verification index, not a
claim that every row is fully implemented.

Status key:

- Covered: current analyzer or query behavior has dedicated support or committed
  coverage.
- Partial: the surface flows through existing Roslyn operations, but some
  semantics are not first-class yet.
- Conservative: SharpProof deliberately reports or preserves an unknown or
  impure result until tighter modeling exists.
- Gap: there is no dedicated implementation or regression coverage yet.
