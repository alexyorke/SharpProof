## Scope and stop condition

The baseline inventory contains every Git-tracked file at the exact commit
above: 838 files and 249,555 physical text lines. Git's text and blob probes
classified all 838 files as text, so no binary was substituted for line-level
review. The manifest fixed each path, full blob SHA-1, physical line count,
nonblank line count, category, and reviewer before inspection.

Ten read-only Luna Max reviewers received non-overlapping greedy,
size-balanced shards. They could inspect and execute repository code but could
not modify repository files. The Sol Max coordinator independently reproduced
each proposed deletion or simplification, including non-call-graph consumers:
MSBuild imports, analyzer and source-generator loading, reflection, package
payload composition, workflow and acceptance entry points, catalog parity,
and dynamically invoked PowerShell. Only the coordinator changed files.

The first cross-shard synthesis produced cleanup candidates. After those
changes, a separate bounded convergence pass rechecked retained configuration,
dynamic consumers, and cross-project duplication. The audit stops only after
that pass reports no new independently confirmed cleanup and every baseline
path has a verdict in the ledger below.
