# Exhaustive code-usefulness audit

## Scope and fixed baseline

This document records the repository-wide usefulness audit requested for the clean `verifier-process-supervisor` product tree. The fixed baseline is commit `c4678ebb2` (the exact pre-cleanup checkpoint); the result is measured at `HEAD` `7eecd2a02`. `BUGS.md` is the separate defect ledger. The baseline ledger covers every tracked UTF-8 text file at that commit; binary files receive provenance/package-reference checks but no line-by-line text verdict.

The audit used ten non-overlapping, line-balanced Luna Max read-only shards. Shards inspected product code, tests, generators and generated outputs together, build/release automation, package catalogs, samples, and documentation. The Sol Max supervisor reproduced proposed deletions or simplifications through symbol references, generated parity, execution paths, package composition, and focused Docker tests. No production or test file was removed solely to lower a metric, and no cybersecurity work was performed.

## Methodology and evidence

Each ledger row contains the baseline path, blob hash, physical line count, nonblank line count, shard reviewer, category, usefulness verdict, and the candidate simplification decision. Reflection, MSBuild imports, analyzers, generators, package payloads, workflows, catalogs, and dynamically invoked PowerShell were checked by execution or owning-generator/parity evidence rather than ordinary call graphs alone.

Accepted cleanup batches and evidence anchors:

- `a99893153`, `c4a9c6e91`: analyzer activation aggregation, companion intrinsic diagnostics, configuration timing, and summary-depth safety.
- `64bbb6443`, `a7a1dd123`, `549c76510`: Roslyn API/cache assignment coverage, source module initializers, checked division, interval-top canonicalization, trusted selection parity, and malformed companion isolation.
- `5053cd443`, `25261c73f`, `0a2c179f9`: launcher/supervisor publication, worker/protocol result boundaries, atomic generation, fuzz edges, and release-path hardening.
- `7eecd2a02`: explicit reference-to-string lowering boundary, fail-closed multidimensional sequence oracle, and selected unimplemented-partial regression scoping.

Rejected or retained leads are documented in `BUGS.md`: redundant null-guard assignments, the theoretical Lazy race, strict nullable `Contract.Result<T>` identity, configuration conflict fail-closed behavior, the retracted performance-probe race, the disproved Linux backslash-path claim, and the unreachable `RunAttempt` helper. Cache-name detection and semantic outcome-constructor scanning remain documented design limitations (#284/#285). Security/integrity findings #215/#271/#272/#273 remain deferred by explicit user scope.
